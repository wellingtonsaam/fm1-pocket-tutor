# FM1 Pocket Tutor 0.1

The first release: a study firmware for the M-VAVE FM-1, identity `FM-1_902`, derived from fm1-dock (GPL-3.0-only).

- **Guide LEDs**: notes on MIDI channel 16 light the keys (velocity 1–63 dim, 64–126 lit, 127 blinking; CC 123 clears
  them). These notes are not played and never reach the sound module.
- **Name**: `FM1 Pocket Tutor` over USB, `POCKET TUTOR` on the screen.
- **Sound out of the box**: the package carries the FM6 module, so a new install starts playing FM6. To make room, this release has **no Bluetooth MIDI**; it comes back in a later version.
- **Sound**: the FM6 module, now with SAVE: the SAVE button keeps your edits as USER 1…32 in
  flash and writes each one to the log (`tools/fm6_presets.py` copies them to `.md`/`.json`/`.syx`).
- **Lessons**: `docs/prototipo-aulas.html` in Chrome: the 27-key keyboard, lessons (watch → play → check), the song
  catalog by sections, and ChordPro import.
- **Lessons page**: Portuguese, English and Spanish; song modules (`docs/songpacks`).

Tested on a black FM-1 (installed from V15, left to another firmware and back) and in fm1-emu. Attached: `fm1-pocket-tutor-0.1.fwsc`.
